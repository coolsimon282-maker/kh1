## Rules found (23 Nov, f2)

G1. **A tiny fixed-count loop that the target did NOT unroll (`li $4,1; loop: addiu $4,-1; sw; nop; nop; nop;
    bgez $4`, ours: two straight stores): write it with `goto`.** Any `for`/`while`/`do` form is a "real" loop for
    the compiler and a 2-iteration one is unrolled completely; a label + `if (i >= 0) goto loop;` is not seen by
    the loop pass at all, so nothing is unrolled, reversed or strength-reduced: write the counter and the
    pointer exactly as the assembly has them (`i = 1; loop: i--; *p++ = 0; if (i >= 0) goto loop;`).
    Proven by func_00206E28. Probably also a5's "short loops without gcc's nops need another loop shape".
G2. `n = A - 1; if (n < B) B = n;` with the two registers swapped: write the expression twice, no variable:
    `if ((u32)B > (u32)(A - 1)) B = A - 1;` (func_00213D00).
G3. `n += (t > 0)` with the addu operands the other way round (target `addu n, flag, n`): add INTO the flag
    variable and copy back: `s32 b; if (t < 3) { b = t > 0; b += n; n = b; }` (func_001F41C0).
G4. `(c - 1) * 16` folded to `c * 16 - 16` where the target has `addiu -1; sll 4` on c's own register: reuse the
    variable, `c = (c - 1) << 4;`. Block order / own `jr` per block: early `return`s instead of if/else
    (func_001FD688). Two stores in the "wrong" order around a division: compute the quotient into a local first,
    then store both (func_001FD5E0).
G5. **`xori $3,$2,0` before a `movz`/`movn` (a2: "ternary / if-return all give the plain movz form"): the
    conditional move was made late from a real `if`, with the tested variable REUSED for the constant:**
    `d = f(...); r = 2; if (d != 0) { d = 4; r = d; } return r;` gives `li a0,2; xori v1,v0,0; li v0,4;
    movz v0,a0,v1` (func_001E8DA0). The mirror form (`r = 4; if (d == 0) { d = 2; r = d; }`) gives movn.
